La configuration et exécution du framework d'analyse dynamique Android Medusa dans un environnement isolé via Docker. L'objectif est de connecter l'outil à un émulateur Android (comme Genymotion) pour analyser des applications tierces (telles que OWASP Uncrackable 1).
